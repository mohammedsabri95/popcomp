# popcomp 0.1.0

Initial release preparation; authorised private repository upload. Public publication remains pending.

- Population-referenced count modelling through R-INLA with age-basis covariate effects and spatial/random effects.
- Posterior marginal and typical-unit contrasts, Wasserstein-1 distances, mean displacements and tolerance summaries.
- Simulated examples, manual help pages and analytic correctness tests.
- Input validation rejects invalid counts, time indices, covariates, unordered W1 support and unknown contrast types while preserving compatible structural zeros.
- Statistical model and prior defaults are preserved. Documentation distinguishes the finite-Gaussian intercept approximation from exact conditional Bayesian equivalence.
